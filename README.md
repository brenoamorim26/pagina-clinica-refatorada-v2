# Clínica Bem me Quer

Site institucional responsivo desenvolvido com React, Vite e Material UI.

> **Aviso:** Os dados e as informações apresentados neste projeto são fictícios e foram incluídos apenas para fins de aprendizado.

## Requisitos

- Node.js 20 ou superior
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Páginas

- `/` — início e especialidades
- `/sobre` — apresentação da clínica
- `/horarios` — horários por especialidade
- `/contato` — canais de contato e formulário

O formulário prepara uma mensagem no aplicativo de e-mail do visitante. Para receber mensagens diretamente pelo site, será necessário integrar um serviço ou backend.
